## Как продолжить

Следующее поручение агенту:

> Прочитай AGENTS.md и migration/STATUS.md. Выполни инвентаризацию, затем пилот переноса с новым дизайном и поэлементной сверкой содержания по плану, сохрани все результаты в этом репозитории. Pages пока не публикуй.

Агент использует инструкции из `.agents/skills/`. Пользователю не нужны экспорт базы, установка Joomla, написание программ или подготовка файлов вручную.

Будущий адрес при стандартных настройках проекта: `https://r2force.github.io/ufalit/`. Он пока не опубликован. Существующий `LICENSE` сохранён; исходные указания авторства материалов должны переноситься вместе с ними.
