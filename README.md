# Уфа литературная — статическая копия

Сайт опубликован: **https://r2force.github.io/ufalit/**

Перенос с [исходного сайта](https://ufalit.ufacsdb.ru/) завершён. История работ, отчёты и исходные ссылки сохранены в архиве проекта.

GitHub Actions собирает страницы из `site/` и общих шаблонов. Публикация собранного каталога `site/` запускается вручную в [workflow Pages](.github/workflows/pages.yml) с параметром `deploy`. Прежняя ветка `gh-pages` сохранена как история первой публикации.

Общий каркас, шапка, меню, хлебные крошки и футер редактируются в [templates/](templates/). В начале каждого исходного HTML нового дизайна между строками `---` записаны параметры страницы в JSON. Поле `title` задаёт заголовок вкладки, `breadcrumbs` — последовательность подписей и ссылок, `styles` и `scripts` — дополнительные файлы из `site/assets/`. После параметров идёт HTML основного материала. На главной метка `<!-- main -->` отделяет вступление перед основным содержанием. В фотоальбомах список `photos` хранит снимки в порядке показа. На месте `<!-- photos -->` сборка вставляет карточки по [шаблону фотографии](templates/photo.html). Обычная подпись хранится в `caption`, подпись с разметкой — в `caption_html`. Для отдельного описания изображения используется `alt`. Альбом автоматически подключает скрипт просмотра. Снимки загружаются с `loading="lazy"`; для исключений укажите `"loading": "eager"` либо `"loading": null` (пропустить атрибут). Метка `<!-- photo-count -->` выводит число снимков с русским склонением.

В каталоге у ссылки на альбом укажите `data-cover` с путём к обложке. Сборка вставит изображение перед подписью ссылки. На страницах с аудио массив `tracks` задаёт дорожки в порядке показа. Поля каждой записи — `id`, `title` и `src`. Метка `<!-- tracks -->` выводит плееры и ссылки для скачивания. GitHub Actions собирает готовые HTML перед публикацией.

Для локального предпросмотра из корня репозитория соберите сайт в новый каталог и запустите сервер.

```sh
preview_dir=$(mktemp -d)
python3 scripts/render_site.py --output "$preview_dir/site"
python3 -m http.server --bind 127.0.0.1 --directory "$preview_dir"
```

Предпросмотр доступен по адресу `http://localhost:8000/site/`.
