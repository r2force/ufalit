# Уфа литературная — статическая копия

Сайт опубликован: **https://r2force.github.io/ufalit/**

Перенос с [исходного сайта](https://ufalit.ufacsdb.ru/) завершён. История работ, отчёты и исходные ссылки сохранены в архиве проекта.

GitHub Actions собирает страницы из `site/` и общих шаблонов. Публикация собранного каталога `site/` запускается вручную в [workflow Pages](.github/workflows/pages.yml) с параметром `deploy`. Прежняя ветка `gh-pages` сохранена как история первой публикации.

Общий каркас, шапка, меню, хлебные крошки и футер редактируются в [templates/](templates/). В начале каждого исходного HTML между строками `---` записаны параметры страницы в JSON. Поле `title` задаёт заголовок вкладки, `breadcrumbs` — последовательность подписей и ссылок, `styles` и `scripts` — дополнительные файлы из `site/assets/` (скрипты и стили справочника, читального зала, просмотра иллюстраций, аудиостудии и библиографии подключаются автоматически по разметке и параметрам). После параметров идёт HTML основного материала. На главной метка `<!-- main -->` отделяет вступление перед основным содержанием, параметр `atlas` включает карту на месте `<!-- atlas -->`, а массив `guide_cards` заполняет карточки разделов.

Карта использует адаптированный виджет из `design_example/ufamap/`. Единственный источник её мест, координат, фотографий и описаний — [atlas-places.json](templates/atlas-places.json); сборщик формирует из него список ссылок, начальную карточку и JSON для браузера. Оформление карты — `site/assets/atlas.css`, логика главной — `site/assets/ufalit-map.js`, общий виджет — `site/assets/map-widget.js`. Поиск и фильтры работают и при недоступной подложке. Библиотека MapLibre GL JS 6.19.0, её CSS, worker и лицензия находятся в `site/assets/vendor/maplibre-gl/`; картографическая подложка и шрифты подписей загружаются с OpenFreeMap. Атрибуция поставщиков сохранена на карте. Проверка: `node scripts/test_home_map.js`.

Порядок добавления и исправления меток, описание полей, категории фильтров и проверки собраны в [инструкции по меткам карты](AGENTS.md#метки-литературной-карты).

Координаты демонстрационного сада исправлены по [географической привязке сада Аксакова](https://ru.wikipedia.org/wiki/Сад_Аксакова); для музея Гафури использован [адресный справочник](https://ufa.spravka-region.ru/tags/muzei/Memorialnyj-dom-muzej-M-Gafuri-3), для библиотеки — [привязка здания на ул. Мингажева, 109](https://bashkortostan.spravochnika.ru/c-ufa/biblioteki). Точка улицы Мустая Карима обозначает её центральный участок, а не отдельное учреждение. Тексты и архивные фотографии сохранены из прежней карты и раздела памятных мест.

В фотоальбомах поле `heading` задаёт заголовок альбома, а список `photos` хранит снимки в порядке показа. Если в теле страницы нет явной метки `<!-- photos -->`, сборка формирует альбом по [шаблону фотоальбома](templates/gallery-album.html) и вставляет карточки по [шаблону фотографии](templates/photo.html). Обычная подпись хранится в `caption`, подпись с разметкой — в `caption_html`; для отдельного описания изображения используется `alt`. Снимки загружаются с `loading="lazy"`; для исключений укажите `"loading": "eager"` либо `"loading": null` (пропустить атрибут). Метка `<!-- photo-count -->` выводит число снимков с русским склонением. В статьях иллюстрации внутри `.material-figure`, `.material-inline` и `.legend-figure` записываются как обычные `<img>` и при сборке автоматически оборачиваются ссылкой на оригинал по [шаблону иллюстрации](templates/zoom-image.html).

В каталогах у ссылки на альбом укажите `data-cover` с путём к обложке либо `data-writer` с ключом писателя из [writers.json](templates/writers.json) — сборка подставит портрет, имя и адрес раздела. В справочниках (`personalities`, `places`, `awards`) шапка формируется по `heading` и `intro` через [шаблон баннера](templates/directory-banner.html). На страницах с аудио объект `audio_studio` формирует [аудиостудию](templates/audio-studio.html), а массив `tracks` (`id`, `title`, `src`) на месте `<!-- tracks -->` выводит дорожки по [шаблону аудиозаписи](templates/audio-track.html). На видеостраницах поле `heading` и массив `videos` (`title`, `src`, при необходимости `id` и `description`) формируют страницу по [шаблону видеоподборки](templates/video-album.html) и выводят карточки по [шаблону видеозаписи](templates/video.html). GitHub Actions собирает готовые HTML перед публикацией.

Для локального предпросмотра из корня репозитория соберите сайт в новый каталог и запустите сервер.

```sh
preview_dir=$(mktemp -d)
python3 scripts/render_site.py --output "$preview_dir/site"
python3 -m http.server --bind 127.0.0.1 --directory "$preview_dir"
```

Предпросмотр доступен по адресу `http://localhost:8000/site/`.
