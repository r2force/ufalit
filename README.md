# Уфа литературная — статическая копия

Сайт опубликован: **https://r2force.github.io/ufalit/**

Источник: [ufalit.ufacsdb.ru](https://ufalit.ufacsdb.ru/). Публичное содержание сохранено в обычных HTML/CSS и локальных файлах. Видео представлены ссылками на оригиналы по поручению пользователя. Текущий срез опубликован 17 ноября 2026 года без изменения оформления; редизайн отложен до предоставления примера.

Публикация: только папка `site/` из ветки `main` через [GitHub Actions](.github/workflows/pages.yml). Все инструкции, лицензии, реестры, отчёты и доказательства проверок остаются в этом же репозитории вне папки сайта. Изменения `site/`, шаблонов или скрипта генерации в `main` запускают публикацию автоматически. Прежняя ветка `gh-pages` сохранена как история первой публикации и больше не используется как источник.

Общий каркас, шапка, меню, хлебные крошки и футер редактируются в [templates/](templates/). В начале каждого исходного HTML нового дизайна между строками `---` записаны параметры страницы в JSON. Поле `title` задаёт заголовок вкладки, `breadcrumbs` — последовательность подписей и ссылок, `styles` и `scripts` — дополнительные файлы из `site/assets/`. После параметров идёт HTML основного материала. На главной метка `<!-- main -->` отделяет вступление перед основным содержанием. В фотоальбомах список `photos` хранит снимки в порядке показа. На месте `<!-- photos -->` сборка вставляет карточки по [шаблону фотографии](templates/photo.html). Обычная подпись хранится в `caption`, подпись с разметкой — в `caption_html`. Для отдельного описания изображения используется `alt`. GitHub Actions собирает готовые HTML перед публикацией.

Для локального предпросмотра из корня репозитория соберите сайт в новый каталог и запустите сервер.

```sh
preview_dir=$(mktemp -d)
python3 scripts/render_site.py --output "$preview_dir/site"
python3 -m http.server --bind 127.0.0.1 --directory "$preview_dir"
```

Предпросмотр доступен по адресу `http://localhost:8000/site/`.
