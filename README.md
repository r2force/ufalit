## Как продолжить

Следующее поручение агенту:

> Прочитай AGENTS.md и migration/STATUS.md. Выполни инвентаризацию и пилот переноса по плану, сохрани все результаты в этом репозитории. Pages пока не публикуй.

Агент использует инструкции из `.agents/skills/`. Пользователю не нужны экспорт базы, установка Joomla, написание программ или подготовка файлов вручную.
