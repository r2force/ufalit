# Предварительное обследование

11 ноября 2026 года. Это разведка по публичным страницам, не полный обход и не сохранённая копия сайта.

## Что подтверждено

- Репозиторий `r2force/ufalit` доступен на запись, ветка по умолчанию `main`. До harness в корне находились `README.md` и `LICENSE`; Pages не был включён.
- Главная открывается и показывает материал «О проекте» и меню восьми содержательных разделов. В меню также есть «Выход»: это не точка обхода содержимого.
- Статья «Персоналии» содержит очень длинный текст и библиографические списки. Нельзя ограничиться первым экраном или кратким извлечением.
- Фотогалерея использует `com_phocagallery`, имеет список категорий и отдельные страницы категорий. У категории Аксакова в списке отображалось 15 элементов; это не проверенное количество сохранённых фотографий.
- В «Читальном зале» есть ссылки на произведения и текст непосредственно на странице. Типы и доступность всех целевых файлов ещё не проверены.
- «Видеокопилка» — категория Joomla с ссылками на отдельные материалы. Источники видео и пригодность старых проигрывателей ещё не установлены.
- Страницы «Памятные места», «Конкурсы…», «Легенды…» доступны через меню. Ссылки используют `index.php` с параметрами.

## Что ещё неизвестно

Точное число страниц, фотографий и документов; объём файлов; полнота пагинации; оригиналы галереи; состав CSS/шрифтов/скриптов; устройство карты; источники видео; наличие доступного sitemap; ответы robots.txt; реальные входящие старые ссылки; работоспособность отдельных материалов.

Joomla 1.5 указана пользователем, номер версии не подтверждён независимой проверкой.

## Доступ в текущей среде

Просмотр публичных страниц через веб-инструмент и работа с GitHub через подключённый GitHub доступны. Попытка прямого `curl` к исходному домену завершилась ошибкой DNS. GNU Wget и GitHub CLI в PATH не обнаружены. Запрос robots.txt через веб-инструмент не удался: это не подтверждение ни разрешения, ни запрета обхода.

До массового переноса агент должен проверить полноценное скачивание HTML и бинарных файлов в доступной среде. Если оно недоступно, записать блокировку и предложить среду с сетевым доступом, не изображать перенос по данным поискового представления. Работа над документацией и реестрами от этой блокировки не зависит.
