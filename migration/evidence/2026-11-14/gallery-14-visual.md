## Браузер, подкаталог и клавиатура

Запущен обычный Python `http.server` на `127.0.0.1:8878`, с временным symlink `/ufalit` на `site`. В Firefox под адресом `/ufalit/pages/gallery-14/` страница и `../../assets/style.css` загрузились; журнал сервера показывает HTTP 200 для CSS и всех 13 `photo-<ID>.jpg`. Дерево доступности браузера показывает все 13 фигур и корректные локальные адреса `/ufalit/assets/gallery/14/photo-<ID>.jpg`.

В широком viewport осмотрена целиком галерея, карточки расположены четырьмя в ряд, фото не обрезаны по горизонтали, подписи читаемы. В Firefox Responsive Design Mode при 320×480 CSS px меню переносится, галерея становится одноколоночной, изображение и подпись первой карточки помещаются по ширине viewport; явного горизонтального переполнения на осмотренных участках нет. На клавиатуре Tab перешёл через элементы навигации к первой фотографии (ссылка «Автограф»), Enter открыл локальный `photo-639.jpg`; Firefox распознал JPEG 3264×2448.

Скриншоты здесь не сохранены; это визуальное наблюдение живого окна, а не прикреплённый артефакт. Временный сервер был остановлен после проверки; сайт не редактировался.

## Разметка и ограничения

В target использованы `figure`, `a`, `img`, `figcaption`, семантическая навигация и внешняя таблица стилей. Устаревших HTML-тегов, презентационных HTML-атрибутов, inline-style и меток Joomla/MCE в target не обнаружено. Все 13 целевых файлов существуют. Внутренние ссылки страницы относительные и в браузере сохранили prefix `/ufalit/`; footer ведёт на внешний `http://csdb.ufanet.ru`, его доступность не проверялась.

Визуальное сравнение выполнено для всех 13 локальных файлов, показанных Firefox; исходные тела сравнивались побайтно через SHA-256, а source captions/order — по сохранённым HTML snapshots. Старые Joomla-детали не запускались как сайт, и не выполнялась проверка внешнего footer.
