# Проверка запуска под `/ufalit/`

Дата проверки: 2026-11-14. Проверка read-only; файлы сайта и Git не менялись.

## Настройка

Для проверки был создан временный каталог `/private/tmp/ufalit-subpath-root` с symlink `ufalit` на `site`. Запущен штатный статический сервер Python `http.server` на `127.0.0.1:8877` — без собственного серверного кода. Обычный запуск не смог выполнить bind (`PermissionError: Operation not permitted`); запуск на порту 8765 с разрешением завершился `Address already in use`. На 8877 сервер запустился и был остановлен после проверки.

Обычный терминальный клиент не видел локальный сервер из своей сетевой изоляции, поэтому HTTP ответы проверялись запросами браузера Firefox; статусы 200 зафиксированы стандартным журналом `http.server`.

## Результат

- Главная `GET /ufalit/` — **200**; в браузере открылся сайт с базовым оформлением. Проверен широкий экран.
- CSS `GET /ufalit/assets/style.css` — **200**.
- Вложенная страница `GET /ufalit/pages/gallery-12/` — **200**. Дерево доступности браузера показывает содержимое страницы и подписи галереи; локальные переходы и ресурсы используют префикс `/ufalit/` (например, `/ufalit/assets/gallery/12/photo-620.jpg`).
- Запросы браузера к оригиналам gallery-12 `photo-620.jpg`—`photo-638.jpg` (18 файлов, в последовательности страницы пропущен номер 625) получили **200** по журналу сервера. Проверка была HTTP-загрузкой, не сравнением содержимого файлов.
- Браузер также сам запросил `/favicon.ico` и получил **404**. Это не ссылка страницы и не проверялось как часть требуемого набора ресурсов.

## Ограничения

Узкий экран / responsive mode проверить не удалось: браузер перестал отвечать на управление UI, поэтому мобильную компоновку не подтверждаю. Скриншоты в отчёт не сохранены. Проверка не доказывает работу каждой ссылки сайта, а подтверждает перечисленные маршруты и файлы под подкаталогом. В журнале сервера также есть запросы из других ранее открытых вкладок; они не относятся к данному результату.
