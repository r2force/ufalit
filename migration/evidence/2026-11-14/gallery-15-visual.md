## Firefox / подкаталог / клавиатура

Открыл страницу в Firefox через штатный Python `http.server` по адресу `http://127.0.0.1:8878/ufalit/pages/gallery-15/`. Запрос страницы, CSS и всех 17 URL изображений под `/ufalit/assets/gallery/15/` завершился HTTP 200 по журналу сервера. Firefox распознал открытое отдельно первое JPEG как `641 × 857`.

- В широком окне просмотрены все карточки: четыре колонки, подписи под соответствующими фото, все файлы отображаются.
- В Firefox Responsive Design Mode при `320 × 480` CSS px сетка стала одноколоночной; фото и подпись видимой карточки помещаются в ширину. На просмотренном участке горизонтального переполнения не заметил.
- Клавиатурный фокус проходил по ссылкам. Tab привёл к первой фотографии; Enter открыл связанный локальный `0 (1).jpg` под `/ufalit/`.

Скриншоты наблюдались в окне браузера, но как файлы не сохранялись. Внешний footer `http://csdb.ufanet.ru` не проверялся на доступность.

## Разметка и пределы

Target использует `figure`, `a`, `img`, `figcaption`, навигационные landmark-и и общий CSS. В `site/pages/gallery-15/index.html` не обнаружены Joomla/MCE маркеры, устаревшие элементы, презентационные HTML-атрибуты или inline `style`. Отсутствующую метку `0 (4)` не добавляли. Проверка визуального сюжета сделана по рендеру target, а принадлежность local body источнику доказана отдельно пересчитанными SHA-256 исходных повторных загрузок и локальных JPEG; source-to-target не выводился только из количества элементов. Внешние адреса и актуальное состояние прежнего сайта вне сохранённых HTML-снимков не проверялись.
