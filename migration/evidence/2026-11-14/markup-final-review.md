# Независимая проверка финальной очистки разметки

Дата: 14 ноября 2026 года  
Проверено относительно `git HEAD`; файлы сайта и Git не изменялись. Единственный созданный файл — этот отчёт.

## Проверки исходников

- Для `reading`, `personalities`, `medal`, `stipend` и `places` сравнил DOM-текст тела страницы, последовательность `href` и `src`/`poster`/`srcset` с содержимым из `git HEAD`. Во всех пяти случаях совпадение полное после ожидаемых преобразований; ссылки и медиаресурсы сохранены.
- Для `personalities` удаление ровно 19 старых элементов `<div class="clr"></div>` из версии `HEAD` даёт текущий HTML побайтно после нормализации окончаний строк. Остальной DOM, включая изображения, атрибуты, порядок и текст, не менялся. Текущая страница содержит 19 `.person-body`, не содержит этих clearfix-элементов; `personalities-cleanup.css` задаёт `display: flow-root` для `.person-body` ровно один раз. Существующие float-правила, включая мобильные правила для изображений, сохранены.
- В `reading` старые классы `sp-accordion`, `sp-accordion-style2` и `sp-accordion-inner` удалены; эквивалентные нейтральные классы присутствуют. Проверка DOM после этих трёх замен совпадает с `HEAD`; `accordion_sp1_id70` сохранён. Селектор `.reading-index .sp-accordion-inner` заменён на `.reading-index .reading-index__section-content`; декларация нижнего отступа `padding-bottom: .5rem` сохранена. Встроенных `<style>` здесь не было.
- В `medal`, `stipend` и `places` было по одному встроенному `<style>`, теперь их нет. Содержимое каждого из трёх блоков присутствует в `site/assets/page-layouts.css` без изменения селекторов и деклараций (сравнение после удаления пробельных различий). Внешний CSS подключён после базового CSS для `medal`/`stipend` и после `places-cleanup.css` для `places`, сохраняя прежнее положение встроенных правил в каскаде.

## Браузер

Через Firefox и временный стандартный статический сервер проверил страницы под `/ufalit/`. В широком окне просмотрел читальный зал и раскрытый блок Аксакова на странице персоналий: заголовки, фото и обтекающий его текст видны. В эмуляции узкого экрана 320×480 просмотрел читальный зал, а также раскрытый блок Аксакова: навигация и текст переносятся, изображение помещается по ширине, текст идёт ниже изображения; явного горизонтального переполнения не увидел.

Визуально не проверены страницы `medal`, `stipend` и `places`, а также computed styles и клавиатурная навигация. Поэтому вывод о поведении перенесённых CSS на этих трёх страницах основан на сравнении исходных правил и порядке подключения, не на браузерной эквивалентности. Также не проверялись внешние ссылки и отображение на других браузерах.

## Итог

По проверенным HTML-данным потерь текста, ссылок или медиа-путей не обнаружено; изменения соответствуют заявленным классам/селектору, удалению 19 пустых clearfix-элементов и переносу трёх встроенных CSS-блоков. В Firefox проверены только читальный зал и раскрытая персоналия на широком и узком экранах. Браузерное поведение CSS, перенесённого с `medal`, `stipend` и `places`, остаётся непроверенным.
