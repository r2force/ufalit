# Фотографии категории Аксакова

11 ноября 2026 года загружены 15 изображений по ссылкам скачивания из сохранённой страницы категории. Порядок адресов, коды ответа, MIME и число байтов — в `responses.tsv`. Все ответы — HTTP 200, `image/jpeg`; файлы распознаны как JPEG. Оригинальные полученные байты находятся в `site/assets/gallery/aksakov/`, их SHA-256 перечислены в `SHA256SUMS`.

Страницы деталей с подписями сохранены в соседней папке `aksakov-details/`: имя архива соответствует числовому `id` фотографии. Подписи и порядок внесены в `content-parity.csv`. Сами страницы новой галереи ещё не созданы; совпадение размещения и визуальная проверка не заявляются.
