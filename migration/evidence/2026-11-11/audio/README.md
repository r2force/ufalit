# Аудиозаписи читального зала

11 ноября 2026 года последовательно скачаны 18 записей страницы «Стихотворения. Читает Мустай Карим» и пять записей страницы «Стихи в исполнении Зайнаб Назыровой и песни на стихи Мустая Карима». `heads.tsv` содержит предварительные ответы сервера; `downloads.tsv` — фактические ответы и размеры при загрузке. Все 23 ответа — HTTP 200, `audio/ogg`; файлы распознаны как Ogg Vorbis и записаны без преобразования в `site/assets/audio/`. SHA-256 каждого файла — в `SHA256SUMS`.

Порядок и 18 подписей первой страницы сохранены из исходного HTML; у пяти проигрывателей второй страницы отдельных подписей в HTML не было, они обозначены порядковыми номерами. Наличие файлов и элементов управления не доказывает воспроизведение, длительность или идентичность звучания: все записи остаются discovered до проверки.
