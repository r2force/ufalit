# Категории галереи и видеоматериалы

11 ноября 2026 года около 16:27–16:29 UTC последовательно получены 16 страниц категорий и три страницы видеоматериалов. Между запросами выдерживалась пауза; `responses.tsv` содержит фактические HTTP-статусы, типы и размеры ответов. Файлы HTML сохранены без изменения исходных байтов в gzip-архивах; `SHA256SUMS` содержит хеши архивов.

Имя `gallery-N.html.gz` соответствует `id=N` в очереди категорий `migration/pages.csv`, а `video-N.html.gz` — статье видео с `id=N`. Исходные адреса с полными параметрами сохранены в очереди. Категория Аксакова была сохранена в предыдущей партии.

В HTML найдены ссылки на отдельные страницы фотографий и источники проигрывателя AllVideos. На 26 уникальных видео выполнены только HEAD-запросы; `video-heads.tsv` содержит ответ и размер, заявленный сервером. Это не проверка байтов, содержимого и воспроизведения. Сумма заявленных размеров — 897 740 069 байт, два файла превышают 100 000 000 байт. Дальнейшие категории, пагинация, оригиналы фото и содержание вложений ещё не проверены.
