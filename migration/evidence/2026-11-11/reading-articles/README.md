# Страницы читального зала

11 ноября 2026 года последовательно получены 16 страниц, на которые ссылается исходный читальный зал, и печатный вариант его основной страницы. Все ответы записаны в `responses.tsv`; HTML сохранён без изменения байтов в gzip-архивах. Имена 16 файлов соответствуют числовому `id` статьи, а печатной версии — `print-318.html.gz`. SHA-256 архивов записаны в `SHA256SUMS`.

`399-article.html.gz` — контрольное извлечение статьи «Аксаков, С. Т. Аленький цветочек» из сохранённой страницы 399; оно не заменяет оригинальный полный ответ. Две иллюстрации статьи скачаны в `site/assets/reading/aksakov/`, их фактические типы, размеры и хеши записаны в `migration/assets.csv`. Текст статьи сверялся после нормализации пробелов; остальные 15 материалов пока не перенесены.
