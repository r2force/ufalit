## Повторное использование и ограничения

SHA-256 сверены против остальных локальных файлов `site/assets/`. Найден один точный дубликат: `site/assets/gallery/37/01.jpg` идентичен `site/assets/persons/hudaiberdin/01.jpg` (SHA-256 `667ec52d6bfcc93e2e1792e5207ae24ddbe59e6fb28ea4237bf4d43c36cd2f1b`). Оба файла сохранены; существующий файл не перезаписывался. Других точных дубликатов в имеющихся ресурсах нет. Сводка проверки: `reuse-check.tsv`.

Деталь `01` стоит 23-й и последней в исходном порядке, хотя её числовой ID (715) выше ID соседних кадров (675–696); исходный порядок категории сохранён. Регистры `.jpg`/`.JPG` сохранены. На всех полученных байтах системный определитель формата распознал JPEG; пиксельные размеры сняты локально. Визуально проверен первый файл `PA020006.jpg`, он показывает стенд музейной экспозиции и соответствует разделу «Музей, премия».

В ходе загрузки были две исправленные ошибки: первая попытка для `PA020006.jpg` не записала тело из-за отсутствовавшего каталога назначения (заголовки ответа HTTP 200 сохранены как `original-PA020006.failed.headers`); первая попытка для `PA030013.JPG` завершилась сетевым таймаутом без заголовков (пустой файл попытки — `original-PA030013.failed.headers`). Оба оригинала впоследствии скачаны успешно, итоговые файлы и успешные заголовки проверены. Неуспешные попытки не включены в число 23 успешных ответов.

Категория и её детали доступны публично; вход, формы, административные URL и иные источники не использовались. Страницы сайта, общие реестры и Git не изменялись.
