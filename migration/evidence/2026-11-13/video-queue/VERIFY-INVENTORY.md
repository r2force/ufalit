# Независимая проверка инвентаря видеоветви

Дата: 2026-11-13. Сверены только сохранённые HTML и HTTP-заголовки в этой папке; видеотела не загружались.

## Итог

Список раздела, число и порядок плееров, видео-URL и HEAD-метаданные согласованы с `IMAGE-REPORT.md` и `media-metadata.tsv`. Подписи для статей 389 и 388 в таблице совпадают с текстом рядом с плеерами; для статьи 81 таблица использует редакционный маркер `Без подписи`, которого нет в исходнике. Это обозначено в основном отчёте, но поле TSV `caption` само по себе не отличает маркер от исходной подписи.

Найдено ограничение исходных снимков: все четыре HTML-файла объявлены `charset=utf-8` в HTTP `Content-Type`, но содержат невалидные UTF-8 последовательности. Python UTF-8 декодер на каждом файле останавливается на байте `0xF8` (позиции: категория 11591; статья 389 — 15671; 388 — 18868; 81 — 26191). Снимки и указанные SHA-256 при этом побайтно согласуются с размерами в отчёте. Исходные байты сохранены; текст, извлечённый только декодированием как UTF-8, может быть искажён в соответствующих местах.

## Ограничения

- Результат относится к сохранённому срезу от 2026-11-13; актуальность публичного источника повторно не проверялась.
