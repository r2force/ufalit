# Аудит охвата сохранённых источников

Дата: 17 ноября 2026 года. Проверены только уже сохранённые HTML-снимки и текущие `migration/pages.csv`, `migration/assets.csv`, `migration/INVENTORY.md`; сетевых запросов и изменений сайта/реестров не было.

## Итог

Среди ссылок, обнаруженных в сохранённом наборе снимков, подтверждена одна неучтённая ветвь содержимого: категория Phoca Gallery ID 19 «Аксаковские праздники». Её полный URL:

`https://ufalit.ufacsdb.ru/index.php?option=com_phocagallery&view=category&id=19:2012-12-30-06-00-01&Itemid=88`

Ссылка и подпись находятся в `migration/evidence/2026-11-11/gallery-aksakov.html.gz`; соответствующих строки в `pages.csv` и локальной `site/pages/gallery-19/` не обнаружено. Сам снимок родительской категории не раскрывает дочернее содержимое ID 19, поэтому список её фотографий, вложенных категорий и пагинации неизвестен. Это приоритетный пробел для последующего захвата и обхода.

В остальном сохранённые ссылки в основном сопоставимы с локальным содержимым, но закрытость всего сайта доказать нельзя: комплект снимков не является полным рекурсивным обходом, а реестр страниц не отражает все найденные photo-detail ID отдельными строками.

## Охват снимков и реестров

- Просмотрен локальный набор из 631 HTML-файла (`.html` и `.html.gz`) под `migration/evidence/` и ссылочные атрибуты `href`, `src`, `data`, `action`, `poster`.
- В актуальных на дату аудита реестрах 375 строк `pages.csv` (все со статусом `captured`) и 1 675 строк `assets.csv`. Это текущие значения; фраза в `migration/INVENTORY.md`, что `pages.csv` содержит только девять стартовых адресов, устарела.
- Маршрут списка галерей `view=categories` зарегистрирован в `pages.csv` и ведёт на `site/pages/gallery/index.html`.
- Из снимков извлечено 38 уникальных ID маршрутов `view=category`; 37 категорий имеют строки в `pages.csv`. Единственное отсутствующее ID — 19, указанное выше. Остальные 37 сопоставлены с зарегистрированными категориями, в том числе категории, найденные как вложенные.
- Из снимков извлечено 506 уникальных ID маршрутов `view=detail`. Отдельные строки `kind=gallery-detail` есть для 308 ID. Остальные 198 отсутствуют как отдельные записи реестра; они распределяются по уже существующим категориям так:

  Для всех 506 ID найдены существующие локальные целевые файлы галерей и якоря `#photo-ID` на соответствующей странице категории. Значит, эти 198 строк — прежде всего разрыв трассировки `pages.csv`, а не свидетельство отсутствующих фото. В `assets.csv` оригиналы обычно представлены URL файлов `images/phocagallery/...`, а не URL detail-страницы, поэтому сопоставление только по query-ID ресурса также неполно. Пример доказательной пары: detail ID 453 из `migration/evidence/2026-11-12/gallery-31/category.html` ведёт к `site/pages/gallery-31/index.html#photo-453`; оригинал `IMG_0861.jpg` имеет строку `captured` в `assets.csv` и заголовки в `migration/evidence/2026-11-12/gallery-31/original-453.headers`.

## Пагинация, альтернативные маршруты и вложения

- Среди ссылок сохранённых HTML-снимков не обнаружены активные pagination href с ненулевыми `start`, `limitstart` или `page`. Нулевое `limitstart=0` и пустой контейнер `.pagination`, например в `migration/evidence/2026-11-13/video-queue/category.html`, не свидетельствуют о следующей странице. Это вывод только о сохранённых ответах; он не доказывает отсутствие иных страниц пагинации у непроверенных категорий.
- В снимке `migration/evidence/2026-11-11/video.html.gz` найдены два альтернативных feed URL категории ID 3: `https://ufalit.ufacsdb.ru/index.php?option=com_content&view=category&id=3&Itemid=90&format=feed&type=atom` и такой же URL с `type=rss`. Категория зарегистрирована и представлена локально в `site/pages/videos/index.html`, сами feed-представления отдельно в `pages.csv` не отражены. Это альтернативные форматы, не отдельные статьи; их поддержку нужно явно исключить из охвата либо учитывать отдельно.
- `tmpl=component`/`print=1` и `phocaslideshow=1` встречаются как варианты представления статей и фотодеталей. В рамках этого аудита они сопоставлены с теми же локальными статьями или якорями фото; отдельных редакционных страниц для них не выявлено. Штатные `phocadownload=2` запросы — загрузки медиа, а не страницы контента.
- В источниках/учётных материалах сопоставлены с `assets.csv` 26 FLV-файлов, 23 OGG-файла и один PPT. PPT (`/images/stories/videos/literaturnieprazdniki/presentation.ppt`) сохранён как `site/assets/documents/literary-monuments-ufa.ppt`; 23 OGG имеют статус `captured` и доказательства в `migration/evidence/2026-11-11/audio/downloads.tsv`. Среди 26 FLV один (`presentation.flv`) имеет статус `captured`, а 25 ссылок видео ID 81/388/389 остаются `discovered`: серверные HEAD-метаданные есть, тело и воспроизведение не подтверждены. Их полные URL и результаты HEAD зафиксированы в `migration/evidence/2026-11-13/video-queue/VERIFY-INVENTORY.md`, `media-metadata.tsv` и исходных `.headers`.
- Найден маршрут `com_content` с ID 287 в меню снимка `migration/evidence/2026-11-11/home.html.gz`, подпись ссылки — «Выход». Он отсутствует в `pages.csv`, но по подписи похож на служебный выход, а не на статью. Без снимка самого ответа его следует классифицировать отдельно, не добавляя как пропущенное редакционное содержание.

## Что мешает подтвердить закрытие очереди

1. Снимки собраны в разные дни и сериями по выбранным страницам; нет полного протокола обхода всех исходных меню, категорий, дочерних ссылок и страниц пагинации. Ссылка ID 19 показывает конкретную ветвь, не попавшую в текущую карту.
2. Зафиксированные ранее ответы 404 у robots.txt/sitemap не доказывают, что других публичных URL нет. Без нового сетевого обхода нельзя установить текущую полноту источника или проверить неизвестные страницы и динамические варианты.
3. `pages.csv` содержит только 308 из 506 обнаруженных detail ID как отдельные строки, хотя соответствующие локальные якоря найдены. Нужно либо восстановить недостающие записи/связи для аудируемого отображения источника в цель, либо зафиксировать утверждённое правило агрегации detail URL в страницу категории.
4. Категория ID 19 не имеет собственного сохранённого ответа; неизвестны её реальный перечень, дочерние ветви и вложения. До её захвата и проверки дочерних ссылок нельзя закрыть галерейную ветвь.
5. Альтернативные feed/print/slideshow/выход URL не имеют единого статуса scope/excluded в карте URL. Они не обязательно требуют отдельных страниц, однако классификация должна быть явной для воспроизводимого закрытия очереди.
6. `migration/INVENTORY.md` содержит устаревшее описание размера `pages.csv`; документ не отражает текущий реестр. Это затрудняет использование его как авторитетного основания для закрытия.

## Приоритет дальнейшей работы

1. **Высокий:** сохранить ответ категории ID 19 по указанному URL; перечислить и проверить все дочерние категории, detail-ссылки, пагинацию и оригиналы медиа; сопоставить их с локальными целями.
2. **Высокий:** подготовить проверяемое сопоставление всех 198 отсутствующих в `pages.csv` detail ID с категорией, целевым `#photo-ID` и строкой оригинала в `assets.csv`/доказательством скачивания. Не считать найденный якорь доказательством совпадения изображения.
3. **Средний:** назначить scope-решение двум feed URL и вариантам print/slideshow, а также классифицировать маршрут «Выход» ID 287 по допустимому источнику ответа.
4. **Для закрытия всего сайта:** после фиксации перечисленных конкретных пробелов нужен полный согласованный исходный обход или эквивалентный авторитетный перечень URL; текущие сохранённые снимки подтверждают лишь обследованный набор, а не отсутствие других ветвей.
