# Gallery 36 label restoration

Добавлены исходные числовые метки как `<figcaption>` к фигурам с ID 544–567. Перед изменением для каждой метки сверены свежий снимок категории и сохранённый HTML detail; в обоих источниках значение совпало. Исходные `img`, `src`, `href`, `alt`, `title`, порядок фотографий, подписи для ID 542–543 и 845–851 не изменялись.

## Контроль неизменённых частей

- Все 24 исходных метки подтверждены в обоих видах source evidence и совпадают с добавленными `figcaption`.
- Порядок и ID фигур остались прежними; изменено только содержимое `figure#photo-544` … `figure#photo-567` добавлением подписи.
- Девять соседних фигур (`542`, `543`, `845`–`851`) сравнивались до/после целиком и не изменились. Остальные атрибуты и изображение каждой из 24 изменённых фигур сохранены.
- Счётчик галереи и остальная страница не менялись. Исходные detail HTML и обновлённый live category body содержат дополнительные сервисные атрибуты, но они не использовались вместо видимого источникового текста.

Ограничение: это сверка меток и HTML-порядка, а не визуальная проверка идентичности оригинальных фотографий.
