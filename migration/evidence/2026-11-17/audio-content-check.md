# Независимая проверка 23 аудиозаписей

Дата: 2026-11-17

## Результат

Проверены все 23 исходных URL, повторно сохранённых тел, локальных Ogg и целевых элементов `<audio>`. Для каждого файла SHA-256 временного тела `/private/tmp/audio-repeat-NN.ogg` совпадает с записанным SHA источника из `audio-source-check.tsv` и независимо пересчитанным SHA локального файла. Размеры повторной загрузки, целевого файла и записанные байты также совпадают во всех 23 случаях. Таким образом, для этих URL на момент повторной загрузки доказано побайтное совпадение свежего тела с локальным файлом.

По снимкам `migration/evidence/2026-11-11/reading-articles/414.html.gz` и `411.html.gz` сверены исходные URL и порядок. Все 18 названий статьи 414 совпадают с целевыми заголовками буквально и по порядку. У пяти записей статьи 411 снимок содержит URL в плеере, но отдельных видимых подписей рядом с ними нет; целевая страница использует нейтральные заголовки «Запись 1»–«Запись 5» в соответствующем порядке. Эти заголовки не считаются исходными названиями.

В целевых страницах найдены 18 и 5 элементов `<audio>` соответственно. У каждого `source src` и ссылка загрузки ведут на один и тот же существующий локальный файл. Исходные серверные пути из снимков совпадают с путем каждого файла, взятым из URL. Детали по каждому элементу, включая байты, хеши, подписи и статус, приведены в `audio-content-check.tsv`.

Предыдущая запись `migration/evidence/2026-11-14/audio-decode-check.md` описывает успешный muted smoke test Firefox для 23 файлов: конечная длительность, успешные короткие воспроизведения у начала/середины/конца и отсутствие media error. Это подтверждает распознавание и проверенную работу декодера/seek в этих точках. Звук не прослушивался субъективно; полноценное прослушивание и качество звучания не подтверждаются.

## Итог статусов

- `matched`: 23 из 23 — свежий файл, зарегистрированный source SHA, локальные байты, source URL/order и локальная цель согласуются; по предыдущему muted тесту есть ограниченное подтверждение декодирования и seek.
- Различий в SHA, размерах, URL, порядке, `src`/download href или явных подписях не найдено.
- Для статьи 411 отдельная подпись источником не предоставлена; ее нельзя выводить из имени файла. В target стоят только нейтральные нумерационные обозначения.

## Метод и ограничения

Хеши свежих файлов и локальных активов пересчитаны независимо с SHA-256. Пути `source` и `download` разрешены относительно HTML каждой статьи и проверены на существование. Source snapshots содержат JW Player URL; в статье 414 рядом с каждым плеером есть исходная видимая подпись, а в снимке статьи 411 отдельные подписи для пяти плееров не обнаружены. Полная таблица также сохраняет исходные source URLs, номера элементов и показатели предыдущего декодирующего теста.

Побайтное совпадение подтверждает идентичность сохранённого target с телом, повторно полученным по указанному URL при этой проверке; оно не доказывает, что внешний сервер не изменится позже. Muted smoke test не равен субъективному прослушиванию и не устанавливает воспринимаемую акустическую идентичность. Ни одно аудио здесь не прослушивалось человеком.

Изменены только этот отчёт и `audio-content-check.tsv`. Страницы сайта, Git и реестры не изменялись.
