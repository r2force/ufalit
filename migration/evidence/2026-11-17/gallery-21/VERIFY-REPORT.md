## Независимое сравнение свежих оригиналов

После первой проверки были получены отдельные исходные тела `/private/tmp/gallery21-repeat-328.JPG` … `gallery21-repeat-337.JPG` и соседние headers. Все 10 повторных тел проверены независимо: их SHA-256 и размеры совпали с целевыми JPEG и `migration/evidence/2026-11-17/gallery-21/source-check.md`. В повторных заголовках для каждого файла сверены HTTP 200, `image/jpeg`, Content-Length и имя загрузки. Поэтому для gallery-21 побайтная source-body-to-local проверка выполнена для всех 10/10 кадров; это подтверждает байты тела, повторно полученного по указанному URL во время capture, и не обещает неизменность внешнего сервера в будущем.

Визуальный просмотр кадров и браузерный рендеринг не выполнялись. Страницы сайта, Git и реестры не изменялись; дополнен только этот отчёт.
