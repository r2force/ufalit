## Критерии

- `captured`: exact detail URL извлечён из сохранённого HTML; найден локальный detail snapshot; найдено доказательство оригинальной загрузки (запись `assets.csv` со статусом captured и/или исходные download headers/metadata); локальный целевой файл существует; целевой файл страницы содержит соответствующий `#photo-ID`.
- `discovered`: не выполнено хотя бы одно из перечисленных условий. В `notes` приведена конкретная причина; найденный локальный якорь сам по себе не считается доказательством detail capture или скачивания.
- Для всех строк target page/anchor проверялся по текущим `site/pages/gallery-N/index.html`; исходный target назначен по строке категории в `pages.csv`. Ссылки в выборке нормализованы до основного detail href источника, а не slideshow/download URL.

## Неустранённые случаи

- Нет локального detail snapshot: 0.

- Нет обнаруженного доказательства оригинальной загрузки: 0.

- Нет локального якоря `#photo-ID`: 0.

Любой такой элемент остаётся `discovered`, даже если соседняя информация или похожий файл присутствуют. Статус `captured` здесь означает документированное наличие source detail snapshot, download evidence, локального файла и target anchor; визуальное совпадение изображения или браузерное отображение не оценивается.

Candidate предназначен для рассмотрения руководителем; автоматически в общий `pages.csv` не перенесён.
